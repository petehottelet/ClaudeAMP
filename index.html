    Details, Legal & Privacy

    Privacy & your data

    ClaudeAmp has no backend of its own — it runs entirely in your browser (or the local desktop shell) and collects no analytics, no telemetry, and no accounts. API keys you enter stay on this machine — the desktop app encrypts them with your OS keychain, a plain browser keeps them in localStorage — and are never sent to a ClaudeAmp server (there isn't one), so use personal keys you can revoke and clear them any time by emptying the fields and saving. When you pick an API model (Claude, OpenAI, Gemini) your messages go straight from your browser to that provider, handled under its own terms and privacy policy. When you pick a subscription model (Claude Code / Codex) no key is needed: the desktop app relays chat to the claude / codex CLI already installed on your machine over a loopback-only local bridge, and that CLI — not ClaudeAmp — handles auth; Ollama models are likewise discovered from your loopback-only local service. Music plays through YouTube's embedded IFrame player, so that playback is subject to YouTube's / Google's terms and privacy policy.

    CLI workspace access

    Read only is the safe default — the CLI can look but not touch. Enable Allow workspace edits only when you want the selected CLI to create or change files in the workspace folder you choose with Workspace....
