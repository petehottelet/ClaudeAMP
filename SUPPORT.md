# Support

Use [GitHub Discussions](https://github.com/petehottelet/claudeamp/discussions)
for installation questions, provider setup, ideas, and general help. Search
existing discussions before starting a new one.

Use the repository's issue templates for reproducible application bugs. Include
the ClaudeAmp version shown in About, operating-system version, install method,
provider, exact reproduction steps, and relevant terminal output. Never post API
keys, authentication tokens, private prompts, or workspace contents.

Report security vulnerabilities through the process in [SECURITY.md](SECURITY.md),
not through a public issue or discussion.
