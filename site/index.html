CLAUDEAMP

What's in the deck

Your CLI, with a soundtrack.

A REAL TERMINAL

A true PTY running your login shell, skinned like it's 1998. Claude Code, Codex, or ollama run auto-starts in Terminal mode — or use the chat window and keep your conversation docked next to the playlist.

EQ THAT TUNES THE AI

The equalizer is the model panel: pick the brain on the left slider, shape effort, thinking, and personality on the bands. The usage monitor keeps tokens-per-turn and spend on an LCD readout.

MUSIC WHILE YOU SHIP

Fifty iTunes previews out of the box, YouTube and Spotify if you bring accounts, windowshade panels, docking with snap, and the glyph-rain visualizer running the whole time.

PRIVATE BY DEFAULT

Read-only CLI access unless you opt in, API keys in the OS keychain, and a local bridge that never exposes its token to the network. Every release ships with SHA256SUMS.txt and is self-verified on all three platforms before it publishes.
